## qwt-windows-builder：QWT 自动化编译工程上线

- 新建 GitHub 仓库 `jx996/qwt-windows-builder`（公开，main 分支），本地路径 `C:\Users\xujx\Documents\qwt-build`。
- 工作流 `.github/workflows/build-qwt.yml`：
  - `workflow_dispatch` 输入：`qwt_version`（默认 6.3.0，支持 `latest` 自动从 SourceForge RSS 识别最新版）、`qt_version`（默认 6.8.3）、`qt_arch`（默认 win64_msvc2022_64）、`build_examples`（默认 false，禁用 examples/playground/tests）。
  - runner：`windows-latest`（2026-06 起即 Windows Server 2025 + VS2026）。

  - 编译：qmake qwt.pro + nmake（qwtbuild.pri 在 win32 下自带 `debug_and_release build_all`，一次 nmake 同时出 release+debug）。
  - 产物：include/ lib/（.lib）bin/（.dll+.pdb）plugins/designer/，7z -mx=9 打包，命名 `qwt-<ver>-qt<qt简写>-vs2026-x64.7z`，Release tag `qwt-<ver>-qt<qtver>`，gh release upload --clobber 支持覆盖。

## 环境经验（本机）

- 沙箱 bash 缺 usr/bin 工具：需 `export PATH="/c/Users/xujx/.workbuddy/binaries/PortableGit/versions/1.2.0/usr/bin:$PATH"`（sed/grep/head/awk）。
- 全局 git 无 credential.helper；token 从 Windows 凭据管理器读：`CredReadW(target='GitHub - https://api.github.com/jx996', type=1)`，Python ctypes 实现（Add-Type 被沙箱拦截）。token 为 GitHub Desktop OAuth（gho_，scopes: repo, user, workflow）。
- push GH007 私密邮箱：仓库级 `git config user.email jx996@users.noreply.github.com` + `commit --amend --reset-author` 后重推即可。
- Windows curl.exe 的 `-o /tmp/x` 会写到 C:\tmp，bash 重定向 `> /tmp/x` 才正确。
- SourceForge 版本识别：`https://sourceforge.net/projects/qwt/rss?path=/qwt` 列全部版本（best_release.json 数据过旧，勿用）。
